# Jordana Estética Avançada

Landing page desenvolvida para a Jordana Estética Avançada, com foco em apresentação profissional, autoridade visual e conversão de visitantes em contatos pelo WhatsApp.

O projeto foi construído como uma página estática, utilizando HTML, CSS e JavaScript, com uma estrutura leve, responsiva e pensada para campanhas de tráfego pago. A proposta principal foi criar uma experiência clara e objetiva para quem acessa o site, apresentando os serviços, diferenciais, resultados e informações de atendimento de forma elegante, confiável e fácil de navegar.

A landing page conta com seções institucionais, apresentação dos procedimentos, galeria de resultados, chamadas para ação, botões de contato, animações de entrada, estrutura de SEO básico, sitemap, robots.txt e conteúdo organizado para facilitar futuras manutenções. O projeto também foi pensado para funcionar bem em dispositivos móveis, considerando que grande parte dos acessos de campanhas vem pelo celular.

A estrutura do site foi desenvolvida sem dependência de frameworks ou back-end, o que facilita a publicação em plataformas como GitHub Pages, Netlify, Vercel, Cloudflare Pages ou hospedagens tradicionais. Essa escolha também torna o projeto mais simples de manter, mais leve e mais adequado para uma landing page com foco em performance e conversão.

## Tecnologias utilizadas
